## Project Summary

Oasis Intelligence is a web application for exploring agricultural trade and food production data across Gulf Cooperation Council (GCC) countries. It pulls from two real public datasets  FAOSTAT and the World Bank  and combines them into a single searchable, queryable interface that isn't available anywhere else in this form.
Users can search by country or commodity, browse trade flow records, and view country profiles with production and import figures. Interactive charts and plots update dynamically based on live database queries, making it easy to compare trends across countries and commodities.
Users can also save, revisit, update, and delete their own custom analysis views bookmarking specific filter combinations, country selections, and notes for later reference giving each user a personal workspace for ongoing research.

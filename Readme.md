# Team017-SQLPhantoms
OASIS INTELLIGENCE

Oasis Intelligence brings together agricultural trade and food production data for Gulf Cooperation Council (GCC) countries into a single, searchable web application. GCC countries import the vast majority of their food supply due to limited arable land and arid climates, making this data highly relevant to agribusiness professionals. Currently, this data lives across multiple international databases like FAOSTAT and the World Bank with no unified interface to query and compare it easily. Our application solves this by providing a clean, simple frontend over a well-structured relational database.
